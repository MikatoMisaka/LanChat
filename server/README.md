# LanChat Server Edition

This directory reserves the source and deployment files for the planned
self-hosted server edition.

The server edition will retain the LAN P2P client features and add remote text
and image messaging, account login, friend requests, thirty-day offline sync,
FCM notifications, and an administrator web console. Large-file transfer will
remain LAN-only.

The server backend will be selected after comparing mature self-hosted options
against these requirements. Until that evaluation is complete, no server
credentials, database files, Docker secrets, or placeholder runtime service are
included here.
